# Proposal cross-check

The approved proposal (BBIT 4C, Strathmore University, May 2026) is the specification for this
project. `CROSSCHECK.md` records how it was checked against the implementation: how the code maps
onto the proposal's use cases, class diagram, database schema and wireframe, and what was found
missing. Every difference has an entry in `../AMENDMENTS.md`.
